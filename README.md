# TypingPet 🐹

키보드를 누르면 함께 타이핑하는, 조금 멍하고 하찮은 햄스터 데스크톱 펫입니다.

C++과 Win32 API로 만든 작은 개인 프로젝트입니다. 투명한 PNG 이미지 3장을 키 입력에 맞춰 교체하며, 트레이 메뉴에서 크기와 동작을 조절할 수 있습니다.

## 주요 기능

- 다른 프로그램에서 키보드를 입력해도 양손을 번갈아 움직입니다.
- 입력이 약 120ms 동안 없으면 기본 자세로 돌아옵니다.
- PNG의 투명도를 유지하고, 일반 창 위에 캐릭터를 표시합니다.
- 마우스 드래그로 펫을 이동할 수 있습니다.
- 트레이 메뉴에서 일시정지, 숨기기, 종료를 할 수 있습니다.
- 크기를 160 / 240 / 320 / 400px 중에서 선택할 수 있습니다.
- 위치 잠금과 클릭 통과를 각각 설정할 수 있습니다.
- 위치, 크기, 일시정지, 숨김, 잠금, 클릭 통과 상태를 자동 저장합니다.
- 중복 실행하면 새 펫을 만들지 않고 기존 펫을 보여줍니다.
- 모니터 구성이 바뀌어 저장된 위치가 화면 밖이 되면 가까운 모니터의 작업 영역 안으로 이동합니다.

키보드 입력은 애니메이션을 바꾸는 이벤트로만 사용합니다. 입력한 문장을 저장하거나 외부로 전송하는 기능은 없습니다.

빌드하면 `main.cpp`와 같은 폴더에 `TypingPet.exe`가 생성됩니다. 실행 파일은 저장소에 포함하지 않습니다.

## 개발 환경

- Windows 데스크톱 환경
- C++17을 지원하는 MinGW-w64의 `g++`
- 에디터: VS Code 등
- 사용 API: Win32, Raw Input, GDI+, Shell API

별도의 이미지 처리 라이브러리를 다운로드할 필요 없이 Windows의 GDI+를 사용합니다.

## 빌드 및 실행

먼저 터미널에서 컴파일러가 인식되는지 확인합니다.

~~~bat
g++ --version
~~~

저장소 폴더에서 아래 명령어로 빌드합니다.

~~~bat
g++ main.cpp -o TypingPet.exe -std=c++17 -O2 -municode -mwindows -lgdiplus -lgdi32 -lshell32 -Wall -Wextra
~~~

또는 명령 프롬프트나 PowerShell에서 빌드 스크립트를 실행합니다.

~~~bat
.\build.bat
~~~

빌드 성공 후 실행합니다.

~~~bat
.\TypingPet.exe
~~~

`images` 폴더는 실행 파일과 같은 폴더에 있어야 합니다. 프로그램은 현재 터미널 위치가 아니라 실행 파일 위치를 기준으로 이미지를 찾습니다.

프로그램을 수정한 뒤 다시 빌드할 때는 기존 펫을 먼저 종료합니다.

## 조작 방법

| 조작 | 동작 |
| --- | --- |
| 키보드 입력 | 양손 타이핑 애니메이션 |
| 펫을 왼쪽 버튼으로 드래그 | 위치 이동 |
| 펫 우클릭 | 메뉴 열기 |
| 작업표시줄 오른쪽의 햄스터 아이콘 우클릭 | 트레이 메뉴 열기 |
| 메뉴 → 일시정지 | 타이핑 반응 중지 / 재개 |
| 메뉴 → 펫 숨기기 / 보이기 | 캐릭터 표시 전환 |
| 메뉴 → 크기 | 4가지 표시 크기 선택 |
| 메뉴 → 위치 잠금 | 드래그 이동 방지 |
| 메뉴 → 클릭 통과 | 펫 위에서 클릭해도 아래 창으로 전달 |
| 메뉴 → 위치 초기화 | 가까운 모니터의 오른쪽 아래로 이동하고 펫 표시 |
| 메뉴 → 종료 | 프로그램 종료 |

클릭 통과를 켜면 펫을 직접 클릭하거나 우클릭할 수 없습니다. **트레이 아이콘의 메뉴에서 클릭 통과를 해제**할 수 있습니다. 트레이 아이콘이 보이지 않으면 작업표시줄의 숨겨진 아이콘 영역을 확인합니다.

위치 초기화는 위치와 표시 상태를 바꿉니다. 위치 잠금과 클릭 통과 설정은 별도로 유지됩니다.

## 설정 저장

설정은 다음 파일에 저장됩니다.

~~~text
%LOCALAPPDATA%\TypingPet\settings.ini
~~~

메뉴에서 설정을 변경했을 때, 드래그 이동을 끝냈을 때, 정상 종료할 때 저장합니다. 키 입력이나 매 프레임마다 파일에 쓰지 않습니다.

숨김이나 일시정지 상태도 저장되므로, 다시 실행했는데 펫이 보이지 않거나 반응하지 않으면 트레이 메뉴를 확인합니다.

## 가볍게 동작하도록 한 부분

- PNG 3장은 시작할 때 한 번씩 불러옵니다.
- 4가지 표시 크기의 이미지를 미리 준비하고 원본 이미지 객체는 해제합니다.
- 타이핑 중 화면 갱신은 초당 최대 약 29회로 제한합니다.
- 빠른 연속 입력은 묶어서 처리하며, 표시되는 손이 번갈아 움직이도록 합니다.
- 이미 표시 중인 이미지와 같으면 불필요한 갱신을 생략합니다.
- 입력이 멈추고 기본 자세로 돌아오면 애니메이션 타이머를 종료합니다.
- 숨김과 일시정지 상태에서는 키보드 Raw Input 수신 등록을 해제합니다.
- CPU 스케줄링 우선순위를 보통보다 낮게 설정합니다.
- 대기 중에는 메시지를 기다리며, 입력을 계속 확인하는 반복 루프를 사용하지 않습니다.

실제 CPU·GPU 사용률과 게임·방송 프로그램에 미치는 영향은 아직 측정하지 않았습니다. 성능 수치를 보장하는 단계는 아니며, 사용하는 PC와 캡처 방식에서 확인해야 합니다.

## 이미지 교체

`images` 폴더의 PNG 3장을 다른 캐릭터 이미지로 바꿀 수 있습니다.

| 파일명 | 용도 |
| --- | --- |
| `idle.png` | 기본 자세 |
| `left.png` | 화면 왼쪽 앞발 / 손으로 누르기 |
| `right.png` | 화면 오른쪽 앞발 / 손으로 누르기 |

- 배경은 투명한 PNG로 저장합니다.
- 3장의 캔버스 크기는 모두 같아야 합니다.
- 얼굴, 몸, 키보드 위치를 고정하고 손동작만 바꾸면 자연스럽습니다.
- 각 이미지의 여백을 따로 잘라내면 전환할 때 캐릭터가 흔들려 보일 수 있습니다.
- 이미지가 바뀌면 프로그램을 다시 실행해 불러옵니다.
- 현재 구현은 원본의 가로세로 비율을 유지해 표시합니다.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| `g++`를 찾을 수 없음 | MinGW-w64 설치와 PATH 설정 확인 |
| 빌드 중 `Permission denied` | 실행 중인 `TypingPet.exe`를 종료한 뒤 다시 빌드 |
| PNG를 불러올 수 없음 | 실행 파일 옆 `images` 폴더와 파일명 확인. `idle.png.png`처럼 확장자가 중복되지 않았는지 확인 |
| 이미지 크기가 다르다는 메시지 | 3장의 캔버스 크기를 동일하게 저장 |
| 펫이 보이지 않음 | 트레이 메뉴에서 보이기 또는 위치 초기화 선택 |
| 펫을 클릭할 수 없음 | 트레이 메뉴에서 클릭 통과 해제 |
| 드래그가 안 됨 | 위치 잠금과 클릭 통과 설정 확인 |
| 키보드에 반응하지 않음 | 트레이 메뉴에서 일시정지 해제 |

## 개발 메모

C++과 Win32 API를 익히면서 직접 사용할 수 있는 작은 데스크톱 프로그램을 만들어보는 프로젝트입니다.

구현 과정에서 ChatGPT의 도움을 받았으며, 포함된 햄스터 PNG 3장은 AI로 생성했습니다. 위의 캐릭터 이미지는 애니메이션에 사용하는 미리보기이며, 실제 실행 화면을 촬영한 스크린샷은 아닙니다.
